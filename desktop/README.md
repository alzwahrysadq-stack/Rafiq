# رفيق المحاسب — تطبيق الحاسوب

تطبيق مثبَّت على الحاسوب (لا صفحة ويب): شاشة بدء بصورة رفيق المحاسب، طباعة مباشرة على الطابعة الحرارية، وتزامن تام مع هاتف المالك (نفس الحساب).

## التركيب على حاسب المتجر
1. انسخ `rafiq-setup-0.3.4-144.exe` إلى الحاسوب.
2. اضغط عليه مرتين ← «التالي» ← «تثبيت».
3. أيقونة **Rafiq POS** تظهر على سطح المكتب وفي قائمة ابدأ.
4. عند التشغيل: شاشة رفيق المحاسب ← ثم التطبيق.

## الطابعة الحرارية
- من القائمة: **ملف ← إعدادات الطابعة…** ← اختر طابعة الكاونتر ← حفظ.
- **ملف ← طباعة تجريبية** ← يجب أن تخرج فاتورة «بقالة الوفاء» التجريبية.
- كل فاتورة/سند داخل التطبيق تُطبع مباشرة (Ctrl+P).

## التزامن مع هاتف المالك
- نفس حساب المتجر على الحاسوب وهاتف المالك — كل عملية تظهر على الاثنين في اللحظة نفسها.
- أول تشغيل على الحاسوب = جهاز جديد يُعتمد من هاتف المالك (شاشة الأجهزة).

## للبناء محليًا
```
cd desktop
npm install
# وضع التطوير (يشغّل الواجهة من ../web-client):
npm start
# بناء المثبّت:
npm run dist
```
الواجهة تُدمج تلقائيًا في المثبّت عبر `app/` (ينسخها سير العمل `.github/workflows/desktop.yml`).
