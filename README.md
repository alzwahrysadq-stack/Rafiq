## كيف ترفع المشروع إلى GitHub (بدون توكن)

لا تحتاج إلى مشاركة أي توكن معي. اتبع هذه الخطوات من المتصفح:

### الخطوة 1: أنشئ مستودعاً خاصاً
1. سجّل الدخول إلى GitHub.
2. اضغط **+** في الأعلى ← **New repository**.
3. الاسم: `rafiq-app-standalone` (أو أي اسم).
4. اختر **Private**.
5. **لا** تختر أي إضافات (لا README ولا .gitignore)، واضغط **Create repository**.

### الخطوة 2: ارفع الملفات
1. في صفحة المستودع الجديد اضغط **uploading an existing file**.
2. افتح مجلد `repo` على جهازك، وحدّد **كل المحتويات** (ملفات ومجلدات) واسحبها إلى الصفحة.
   - ملاحظة: مجلد `.github` مخفي على بعض الأجهزة. إن لم يُرفع، استخدم الخطوة 2ب أدناه.
3. اكتب رسالة قصيرة مثل `المرحلة 2` واضغط **Commit changes**.

#### الخطوة 2ب (إن لم يُرفع مجلد `.github`)
1. اضغط **Add file** ← **Create new file**.
2. في خانة الاسم اكتب بالضبط: `.github/workflows/android-ci.yml`
3. الصق محتوى الملف من `repo/.github/workflows/android-ci.yml`.
4. اضغط **Commit changes**.

### الخطوة 3: شغّل البناء والاختبارات
1. افتح تبويب **Actions** في المستودع.
2. ستظهر محاولة تشغيل باسم **CI — اختبارات وبناء APK** (تبدأ تلقائياً بعد الرفع).
3. انتظر حتى تنتهي (غالباً 5 إلى 10 دقائق في المرة الأولى).
4. **إن نجحت:** ✅ ستجد ملف `rafiq-debug-apk` في أسفل صفحة التشغيل. نزّله وثبّته على جوالك للتجربة.
5. **إن فشلت:** ❌ افتح الصفحة، وانسخ آخر 30 سطراً من الخطأ الأحمر، وأرسلها لي. لا تحاول إصلاحها بنفسك.

## ملاحظات تقنية

- **الحزم:** Kotlin 1.9.24، Android Gradle Plugin 8.5.2، Room 2.6.1، KSP 1.0.20، Robolectric 4.12.2.
- **الاختبارات تعمل على Robolectric** بدون محاكٍ، لذا تُشغَّل في CI دون الحاجة إلى جهاز.
- **مخطط قاعدة البيانات** يُكتب تلقائياً إلى `app/schemas/` عند كل بناء، ويُرفع كـ artifact.
- **اسم الحزمة** `net.arena.rafiq` مؤقت. يمكن تغييره لاحقاً قبل النشر.
- **الافتراضات (DEFAULT)** لأعمدة التاريخ والقيم الافتراضية تُطبَّق في كود Kotlin. السلوك مطابق للنسخة المرجعية.
- **البناء المحلي غير مطلوب.** كل شيء يُبنى على GitHub Actions حسب قواعد المشروع.
