## ملاحظات
- إصدار النشر يُوقَّع حالياً بالمفتاح التجريبي نفسه (لا تغيير في الهوية، فتتحدّث النسخ فوق بعضها). المفتاح النهائي يحتاج موافقة المالك.
- التزامن مع Supabase: لم يُنفَّذ بعد (بانتظار رابط المشروع والمفاتيح).
