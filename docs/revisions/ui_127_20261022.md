# واجهة رفيق 127 — تصحيحات تجربة المالك

البناء Android على GitHub Actions فقط. الشجرة مبنية على commit fa274c7 الذي أنتج APK 126 الناجح. لا تغيير في applicationId أو مفتاح التوقيع. main لم يُعدّل.

## التغييرات
- سجل الأصناف يستخدم أعمدة عامة مصرحًا بها، والتكلفة من RPC محمي بجلسة مالك حية. مرآة المنتجات لا تطلب select=* أو التكلفة.
- الموردون ضمن سجل الشاشات الفعلي وإخفاء/إظهار الأقسام. تحميلهم الفاشل يظهر رسالة وإعادة محاولة.
- بيع المالك يغلق القائمة فور الضغط، قبل انتظار الخادم. رفض الخادم لا يفعّل وضع البيع ولا يفتح وردية ولا يحفظ بيعًا.
- القائمة وعناصرها موحدة، بما فيها بيع المالك. أخطاء واضحة بالعربية لا تختفي بعد 9 ثوان، ويمكن إغلاقها؛ تُزال الرسالة القديمة عند الانتقال إلى شاشة مختلفة.
- حد الأجهزة لا يفرغ لوحة المالك. تنبيه ثابت ورابط إلى إدارة الأجهزة. نقل اعتماد جهاز مالك قديم من الحساب والنوع نفسيهما إلى الحالي لا يتم إلا باختيار الجهاز وموافقة واضحة. لا حذف أجهزة، لا رفع للحد، لا نقل جهاز عامل. الخادم يمنع النقل إذا للجهاز القديم وردية/جلسة بيع نشطة، ويحتفظ بسجل تدقيق ويمنع تكرار النقل عند إعادة الطلب.
- القراءة العامة للأصناف متاحة فقط وفق RLS الأصلي. لا منح تكلفة الشراء للدور authenticated ولا السماح للدور anon بمسارات الإدارة.
- تحسين فعلي لتخطيط الشاشات: القوائم أولًا، النماذج المالية الأصلية محفوظة داخل أقسام قابلة للفتح، اختصارات تفتح النموذج وتركّز الحقل، بطاقات وأرقام وترويسة وتنقّل سفلي أصغر ومتناسق، دعم الهواتف والوضع الليلي وتقليل الحركة.
- تقرير تقييم المخزون لا يستبدل تكلفة غير متاحة بصفر وهمي.

## التحقق قبل الرفع
- مجموعة اختبارات Pilot كاملة: ناجحة؛ اختبارات المزامنة 86، الأساسيات 5، التنقل الجديد 7.
- اختبارات SQL محلية معزولة ببيانات مصطنعة: ملكية تكلفة الأصناف، رفض العامل/المجهول/متجر آخر/جلسة غير حية؛ نقل اعتماد بإذن المالك فقط مع ثبات عدد المقاعد وتدقيق ومنع الجلسات النشطة.
- متصفح Chromium حقيقي باستخدام استجابات مصطنعة فقط، لا اتصال بمتجر المستخدم: المقاسات 360،390،412،820،1280؛ تنقل الموردين والأصناف والمتابعة وبيع المالك عند الرفض والقبول؛ لا تجاوز أفقي ولا أخطاء JavaScript غير معالجة؛ فحص موافقة نقل الاعتماد دون تنفيذه؛ لا حفظ بيع/فتح وردية/إرسال رسالة.
- قاعدة المستخدم بعد إعداد المسارات: 4 أجهزة معتمدة وطلب واحد معلق، وصفر عمليات نقل اعتماد. لم يُحذف/يُلغَ/يُنقل أي جهاز فعلي ولم تُغيّر بيانات البيع.

## ما لا تثبته الاختبارات
ليست تجربة على هاتف المستخدم نفسه. لا تُعد نجاح البناء تأكيدًا لكل وظائف البيع والصوت والطباعة على جهازه؛ يلزم فحص الجهاز بعد تثبيت التحديث. لا إعادة تنفيذ ترحيلات الشجرة القديمة على الخادم القائم.
